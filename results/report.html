Central finding

Across every benchmark, base-class accuracy is strong (56–69%) but novel-class accuracy is the bottleneck (16–31%). The whole improvement study targets this gap. Of five levers tested, only transductive prototype rectification improved all metrics reliably; logit-bias and inference-time augmentation did not, and the CLOSER-style representation objective helped one dataset and hurt another.

01Problem & background

What FSCIL is, and why it is hard.

Few-Shot Class-Incremental Learning (FSCIL) asks a model to keep learning new categories after deployment — from only a handful of examples per class — without retraining from scratch and without forgetting. Training arrives as a stream of sessions with disjoint label spaces; after every session the model is evaluated on all classes seen so far.

Two failure modes define the problem:

  • Catastrophic forgetting — updating on new classes overwrites old decision boundaries, so base-session accuracy collapses over time.
  • Few-shot overfitting — with 5 examples per new class, direct fine-tuning memorises the samples instead of learning a generalisable boundary.

The mainstream fix — and the framework this project uses — is to freeze the backbone after the base session and classify new classes by nearest-prototype matching. This sidesteps both failure modes but shifts the entire burden onto the quality of the representation learned once, in the base session. That single dependency is exactly what the improvement study (§7) probes.

02The STAG-STI architecture

A graph-attentive, contrastively pre-conditioned pipeline with an ageing memory.

STAG-STI builds class prototypes through an eight-stage pipeline. A frozen backbone extracts features; a projection and a supervised-contrastive head pre-condition the embedding space; a learned topology scorer and a GATv2 attention layer reason over relationships between classes; prototypes are pooled and folded into a persistent memory that ages older classes so they stabilise while recent ones stay plastic. Queries skip the graph and are matched to memory by temperature-scaled cosine similarity.

Fantasy views ×M→ Frozen backbone fθ→ Projection Wₚ→ SupCon head→ Topology gφ→ GATv2→ Prototype pool→ STI memory Hₜ→ Cosine classifier

The three components that the deck frames as the contribution — contrastive pre-conditioning, topology-aware graph attention, and the spatio-temporal (age-decaying) memory — are each isolated in the ablation study (§6). The model's mathematics were left unchanged throughout this work; every change was to the surrounding data, evaluation, and tooling, plus two opt-in hooks used only for the ablations.

03Datasets & evaluation protocol

Three standard benchmarks on official splits, plus a cross-domain stress test.

To make the numbers directly comparable to the literature (FACT, SAVC, CLOSER), all benchmarks use the official CEC/FACT class splits, vendored into the repository. The incremental support at evaluation uses the exact few-shot samples named by those split files, not random draws.

On the cross-domain protocol

There is no standard miniImageNet→CUB benchmark, so this project defines a reproducible one: the frozen miniImageNet base model, then CUB classes streamed in as 10 sessions of 10-way 5-shot, all CUB images resized to 84×84 with ImageNet normalisation. It should be described as this project's own protocol, not cited.

04What was built

From a CIFAR-only prototype to a reproducible multi-dataset system.

The starting point ran only on CIFAR-100 with a fixed-random split. The engineering work generalised it into a dataset-agnostic, literature-comparable framework:

  • Dataset abstraction — a registry (DatasetSpec) and a single global-label space, selected by a --dataset flag; all three benchmarks share one code path.
  • Official splits — the CEC index files vendored and parsed into a fixed, reproducible class order.
  • Three loader backends — CIFAR index-based; an imagefolder backend with CUB's train_test_split.txt handling; and a mini_csv backend for miniImageNet's flat images/ + CSV packaging.
  • Backbone factory — CIFAR-stem, standard, and ImageNet-pretrained ResNet-18, with per-dataset Phase-A hyperparameters (CUB fine-tunes at a low LR).
  • Deterministic fantasy views — fixed spatial transforms, faithful to the spec's definition of the M deterministic view functions.
  • Standard FSCIL metrics — A_B, A_N, harmonic mean added throughout.
  • Ablation harness — --ablate supcon|topology|agedecay, namespaced so runs never collide.
  • Cross-domain evaluation, transductive rectification (--transductive), and a CLOSER-style base objective (--closer) — each namespaced separately from the baselines.
  • Orchestration — resumable runners, automatic metric-tagged commits, and a self-updating report generator. Every result is a commit on GitHub.

Note on comparability

Moving CIFAR-100 to the official split changed its base-class set, so the numbers here differ from the earlier random-split prototype. The switch is what makes comparison to published methods valid. The legacy run is preserved separately.

Removing any single component leaves overall/final accuracy almost unchanged (≈49.5%) but lowers the harmonic mean — because each removal raises A_B slightly while dropping A_N more. In other words, all three components pull in the same direction: they improve the base↔novel balance. The full model has the best HM (31.9 vs 28.4–29.2). That is a clean ablation story: the contribution is balance, not raw accuracy.

07Improvement study

Five levers aimed at the novel-class bottleneck — what the evidence actually says.

Because A_N is the bottleneck, each lever below targets it. The results are reported honestly: most did not work, and that is itself the finding — the gap to published numbers lives in the frozen representation, not in inference-time tricks.

7.1  Transductive prototype rectification reliable gain

BD-CSPN-style refinement: pseudo-label the unlabelled test queries by nearest prototype, then blend each prototype with the mean of its assigned queries and re-classify. This calibrates the features, and it improved every metric on every dataset — the only lever that did.

7.2  Novel-class logit bias trade-off only

An additive bias on novel-class logits, tuned on a held-out validation split. It trades base accuracy for novel accuracy: raising it lifts A_N and HM but lowers overall accuracy. It is a metric dial, not a capability gain.

7.3  Inference-time augmentation no gain

Test-time augmentation and support augmentation, at both aggressive and mild settings, were neutral-to-harmful. The frozen backbone and deterministic prototypes are calibrated to near-clean inputs, so perturbing them at inference only adds train/test mismatch. On CIFAR, mild TTA left A_N flat (20.5→20.4) while lowering overall accuracy; support augmentation lowered A_N.

7.4  Base-mean feature centering breaks it

Subtracting the base-prototype mean before the cosine classifier destroyed accuracy (CIFAR 48 → 16). Centering distorts the geometry the cosine classifier was trained on — a clear dead end.

7.5  CLOSER-style base objective inconsistent

The deck's own research direction: retrain the Phase-A backbone with a self-supervised contrastive term (spread) plus an inter-class compactness term (pull classes closer for transfer). It genuinely changes the representation — but the effect is dataset-dependent, not a reliable win.

A λ_close sweep on CIFAR showed the base-accuracy cost (~6 points) is a fixed cost of the CLOSER mode — the contrastive term and its aggressive augmentation — not the compactness weight: λ=0.05 matched baseline HM, λ=0.10 was best (HM 34.9), and λ=0.02 was unstable (HM 20.2). The hypothesis that CLOSER would help most on the from-scratch datasets was refuted by miniImageNet, where it hurt everything.

What the study concludes

Only transductive rectification is a dependable improvement. Logit-bias is a trade-off, inference augmentation and centering fail, and CLOSER needs per-dataset tuning to help. No single cheap or one-shot lever closes the gap to FACT/SAVC/CLOSER — that requires systematic per-dataset representation work.

08Bugs found & fixed

Two real bugs, caught by verifying results rather than trusting exit codes.

Bug 1 — CUB collapsed to chance (1%)

The base session built one graph over all 100 classes (400 nodes) — out-of-distribution for a GATv2 trained on 15-way episodes, and numerically unreliable on the Apple-Silicon backend. A 10-way probe gave 88.9%, isolating the cause as scale. Fix: build base prototypes in training-scale chunks (the memory write ignores class-adjacency for new classes anyway). CUB base went 1% → 77.8%.

Bug 2 — cross-domain eval crashed

The novel-class mask was built per-sample instead of per-class (a shape mismatch), and the results used the key acc where the tooling expected accuracy. Both fixed; cross-domain now reports cleanly.

The broader lesson: an exit code 0 from an unattended run is not evidence of a correct result. Every run in this project was checked against expected shapes and sanity values before being accepted.

09Caveats & limitations

Stated plainly, for the writeup.

  • Absolute numbers trail published methods. CUB final 49.7% vs published 57–64%. This is a first working pass with untuned per-dataset hyperparameters; there is real headroom.
  • Published CIFAR-100 / miniImageNet baselines are not filled in — they must come from the source papers, not be invented.
  • The cross-domain protocol is this project's own definition, not a citable standard.
  • Transductive results use a stronger protocol and are labelled as such — they are not directly comparable to inductive published numbers.
  • Single runs, no seeds averaged. The λ=0.02 CLOSER outlier is a reminder that some points need repetition to trust.
  • A few documented assumptions remain in the evaluation (e.g. base prototypes from a random 5-shot draw; the novel-logit-bias heuristic), noted in the code.

10Conclusions & future work

The project delivers a reproducible, literature-comparable STAG-STI system across three FSCIL benchmarks plus a cross-domain test, with a complete ablation and a rigorously honest improvement study. The architecture works; the ablations show its three components jointly improve base↔novel balance; and the improvement study maps the space of easy wins — finding that most do not exist.

The clearest scientific result is diagnostic: novel-class accuracy is the binding constraint, and it is set by the frozen representation. Inference-time tricks cannot move it much; only representation-level changes can, and those need per-dataset care.

Recommended next steps

  1. Adopt transductive rectification as a reported variant — the one reliable gain.
  2. Fill the published-baseline columns and prepare the comparison table for review.
  3. Treat the CLOSER objective as a tuning problem: per-dataset λ_ssl / λ_close sweeps and gentler contrastive augmentation, rather than one shared setting.
  4. Average over seeds for the headline numbers to quantify variance.

11Reproducibility

Everything is a commit; every run regenerates from the checkpoints.

# in-domain (any of cifar100 | miniimagenet | cub200)
python -m fscil.train_session0  --dataset cub200
python -m fscil.eval_incremental --dataset cub200
python -m fscil.eval_incremental --dataset cub200 --transductive

# ablation study (reuses the shared frozen backbone)
python -m fscil.train_session0  --dataset cifar100 --ablate topology --skip_backbone_pretrain
python -m fscil.eval_incremental --dataset cifar100 --ablate topology

# CLOSER-style base objective, and the cross-domain test
python -m fscil.train_session0  --dataset cifar100 --closer
python -m fscil.eval_crossdomain

# regenerate this report's data tables
python scripts/make_report.py

Results are namespaced so nothing overwrites: baselines in checkpoints/<dataset>/, and variants in ablate-*/, closer/, closer_lc*/, and transductive/ subdirectories.

On these numbers. All figures come from single training runs on Apple-Silicon (mps) with the official splits and deterministic fantasy views. They are internally consistent and reproducible from the committed checkpoints, but are a first working pass — not tuned to compete with published state-of-the-art, and not seed-averaged.
